Claude Code on your machines

The Claude button opens the machine and starts Claude Code in it (in the folder you give). It needs a Claude Pro, Max, Team or Enterprise plan, or an API key. Each machine needs this once:

  1. Terminal on: Settings > Control Panel > Terminal (you're here, so it's on).
  2. Add the machine (Add a machine, above) and press Set up access once with its password. On Windows, see step 5 first.
  3. Install Claude Code on that machine: press Open and paste the line for its system.
    Linux or Mac: curl -fsSL https://claude.ai/install.sh | bash
    Windows (PowerShell): irm https://claude.ai/install.ps1 | iex
    Then type exit, open it again, and check with claude --version (it shows a version number).
  4. Sign in once: press Claude. The first time it shows a sign-in link: open it, sign in, and paste the code it gives you back into the terminal. After that it starts straight away.
  5. Windows machines need their SSH server switched on first. On that PC, right-click Start > Terminal (Admin) and paste these one at a time:
    Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
    Start-Service sshd; Set-Service sshd -StartupType Automatic
    New-ItemProperty -Path "HKLM:\SOFTWARE\OpenSSH" -Name DefaultShell -Value "C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe" -PropertyType String -Force (the last one makes PowerShell its shell, so folders on other drives work).
    Set up access only works on Linux and Mac. On Windows, add this Control Panel's key yourself: for an administrator account, paste This Control Panel's key as one line into C:\ProgramData\ssh\administrators_authorized_keys, then run icacls.exe "C:\ProgramData\ssh\administrators_authorized_keys" /inheritance:r /grant "Administrators:F" /grant "SYSTEM:F". For other accounts, it goes in C:\Users\you\.ssh\authorized_keys.

Claude Code runs on that machine with that user's rights, and its own permission prompts still apply. Close the page and it keeps working for 30 minutes: open the Terminal tab again to pick it up.

Select to highlight, Ctrl+C copies a selection (otherwise it stops the program), Ctrl+V or right-click pastes. Closing the page keeps a session for 5 minutes.

    About these switches, and why a tool can show no calls

    A tool with no calls isn't broken. Claude sessions on this machine do many of these jobs with their own built-in tools (the shell, git, reading files, fetching pages). These tools are for apps, remote agents and other people's setups that have no shell here, and every call through them is checked against that client's permissions and logged.

    Switching a tool off makes HomeShed refuse it for everyone: Claude, the agent and this dashboard get a clear "switched off" message until you switch it back on. Scopes (read or write, plus the area) are how access is granted to each app.
