Tools ever used
A tool with no calls isn't broken. Claude sessions on this machine do many of these jobs with their own built-in tools (the shell, git, reading files, fetching pages). These tools are for apps, remote agents and other people's setups that have no shell here, and every call through them is checked against that client's permissions and logged.
Switching a tool off makes HomeShed refuse it for everyone: Claude, the agent and this dashboard get a clear "switched off" message until you switch it back on. Scopes (read or write, plus the area) are how access is granted to each app.

Solve Finds values that satisfy a set of rules, or proves there are none. Written in the solver's own language (SMT-LIB): the example asks for whole numbers x and y with x above 0 and x + y = 10.
Decompose Breaks a job into ordered steps, using your own AI model.
Route Suggests whether your own AI model or Claude should take a job. A suggestion only.
Delegate Lets your own AI model answer when it can, and says when Claude is needed.
