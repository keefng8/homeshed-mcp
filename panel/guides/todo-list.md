# Your to-do list

## What it is
A list of jobs for your AI helpers. You add a task, choose which helper does it, and they work through the list,
overnight too if you want. Every helper writes a note on each task saying what it did.

## Adding a task
On the Control Panel, type what you want done, then pick who does it:
- **a named helper** (a "session": one Claude working in one project folder, such as "my-app"); or
- **"any"**, so whichever helper is free can take it.

Set the **priority** (high, normal or low) so the most important jobs go first.

## Approving tasks
Some tasks wait for your OK before anyone starts them:
- anything that **publishes, deletes, pays, sends, deploys** (puts new code live) or **touches passwords, keys or
  firewalls**;
- every task left to **"any"**.

You approve with one tap. The check is cautious on purpose: an unnecessary tap costs you a second, but a missed one
could act overnight.

## Run without asking
Tick **Run without asking** on a task and it never waits for your OK. Only you can tick it, and no helper can tick it
for itself. It still only runs during the overnight hours you set.

## Overnight
Switch it on in **Settings > To-do list** (it's off by default). You set the hours. During them the helpers take
approved tasks **one at a time**, within your plan budget and nightly limit. When the hours end, you get **one
summary on your phone**.

## Repeating tasks
A task can repeat **daily** or **weekly**. It never closes: after each run it goes back to waiting until its next turn.
Each run's report is kept.

## Reading a report
Every finished task has a report saying:
- what changed (each file);
- the commands it ran;
- the tests and their results;
- what's left;
- **how to undo it**.

## Statuses
- **New**: waiting to be started.
- **Doing**: a helper is working on it now.
- **Done**: finished; the report shows the proof.
- **Failed**: it couldn't be done; the note says why.
- **Blocked**: it's waiting on something else first.
- **Needs owner**: the helper has one question for you. Answer it and the task carries on.
- **Cancelled**: you stopped it.

## Plan
